# Roadmap

The 0.1 MVP prioritizes an explicit review-to-Trash flow. These are planned, not implemented.

1. Disk analysis: incremental tree aggregates, larger bounded scans, performance
   profiling on both personal/work machines, optional treemap and UI automation.
2. Developer artifacts: explicit DerivedData authorization and reproducibility
   evidence; read-only Homebrew/Docker inspection using documented commands.
   No package stores, simulator devices, archives or volumes removed by name.
3. Duplicate detection: size groups, staged hashes, byte comparison, change checks,
   cloud/hard-link/clone handling and at-least-one-copy retention.
4. App uninstalling: reliable bundle association, running-app exclusions, vendor
   requirements, per-item support-file review. Separate from general cleanup.
5. Distribution: stable signing/notarization only if requested, App Sandbox/bookmark
   evaluation, broader OS testing, optional menu-bar health with explicit opt-in.

No GitHub repository has been connected or issues created by this local build.
